Tracciato CSV degli articoli

ItalianoEnglish

Nella versione per Windows e Mac di PalletWise Labels l'anagrafica degli articoli si può importare da un file CSV, per esempio esportato dal gestionale. Il file ha una riga per articolo; la prima riga contiene i nomi delle colonne.

Il modo più semplice è partire dal modello, con le colonne giuste e una riga d'esempio: aprilo con Excel, compilalo e importalo dall'app (Articoli → Importa CSV).

ColonnaObbligatoriaCosa scrivereEsempio
GTINsìCodice EAN dei cartoni: 8, 12, 13 o 14 cifre, con la cifra di controllo giusta4006381333931
DescrizionenoTesto libero; se manca si usa il codice o il GTINBiscotti frolla 500 g
Codice articolonoIl codice del gestionale; se c'è, alle importazioni successive aggiorna l'articoloB01
QuantitànoCartoni per pallet, solo cifre40
Peso nettonoKg per pallet, con il separatore decimale della lingua dell'app (virgola in italiano)523,45
Tipo di datano«Scadenza» (o 17) per la data di scadenza; vuoto o «TMC» per «da consumarsi preferibilmente entro»TMC
Vita (giorni)noGiorni da aggiungere alla data di stampa per la data sull'etichetta; vuoto: data a mano180

Esempio

Descrizione;Codice articolo;GTIN;Quantità;Peso netto;Tipo di data;Vita (giorni)
Biscotti frolla 500 g;B01;4006381333931;40;523,45;TMC;180
Latte UHT 1 l;L01;96385074;60;612;Scadenza;90

Regole

  • Le colonne possono essere in qualsiasi ordine; quelle che non servono si possono togliere.
  • Vanno bene anche altri nomi, in italiano, inglese, tedesco, francese o spagnolo: per esempio EAN, Codice EAN, Barcode per il GTIN; Cod, SKU, Item code, Artikelnummer per il codice; Qty, Colli, Menge per la quantità; Shelf life, Haltbarkeit per la vita in giorni.
  • Separatore: punto e virgola, virgola o tabulazione, riconosciuto dalla prima riga. Testi con il separatore dentro vanno tra virgolette.
  • Codifica: UTF-8 oppure quella di Excel per Windows (Windows-1252), così le lettere accentate restano giuste.
  • Un articolo con lo stesso codice, o senza codice con lo stesso GTIN, viene aggiornato; gli altri si aggiungono. L'ultimo lotto stampato di ogni articolo resta.
  • Le righe con il GTIN mancante o sbagliato vengono scartate: l'app dice quante sono.
  • Gli articoli importati vanno all'azienda in uso nell'app. Con più aziende, importa un file per ciascuna dopo averla scelta.

L'esportazione degli articoli dall'app (Articoli → Esporta CSV) produce lo stesso formato, quindi si può reimportare o usare come modello.

CSV layout for items

In the Windows and Mac version of PalletWise Labels the item catalogue can be imported from a CSV file, for example exported from your ERP. The file has one row per item; the first row holds the column names.

The easiest way is to start from the template, with the right columns and an example row: open it in Excel, fill it in and import it from the app (Items → Import CSV).

Download the template

Columns

ColumnRequiredWhat to enterExample
GTINyesEAN code of the cases: 8, 12, 13 or 14 digits, with the correct check digit4006381333931
DescriptionnoFree text; if missing, the code or the GTIN is usedShortbread cookies 500 g
Item codenoThe code from your ERP; if present, later imports update the itemB01
QuantitynoCases per pallet, digits only40
Net weightnoKg per pallet, with the decimal separator of the app's language (point in English)523.45
Date typeno“Expiry” (or 17) for an expiry date; empty or “Best before” for a best-before dateBest before
Shelf life (days)noDays added to the print date for the date on the label; empty: date entered by hand180

Example

Description,Item code,GTIN,Quantity,Net weight,Date type,Shelf life (days)
Shortbread cookies 500 g,B01,4006381333931,40,523.45,Best before,180
UHT milk 1 l,L01,96385074,60,612,Expiry,90

Rules

  • Columns can be in any order; the ones you do not need can be left out.
  • Other names work too, in English, Italian, German, French or Spanish: for example EAN, Barcode for the GTIN; SKU, Code, Codice for the item code; Qty, Cartons, Menge for the quantity; Shelf life, Days for the shelf life.
  • Separator: semicolon, comma or tab, detected from the first row. Text containing the separator goes in double quotes.
  • Encoding: UTF-8 or Excel for Windows (Windows-1252), so accented letters stay correct.
  • An item with the same code, or with no code and the same GTIN, is updated; the others are added. The last printed batch of each item is kept.
  • Rows with a missing or wrong GTIN are skipped: the app tells you how many.
  • Imported items go to the company in use in the app. With several companies, import one file for each after selecting it.

Exporting items from the app (Items → Export CSV) produces the same format, so the file can be imported again or used as a template.
